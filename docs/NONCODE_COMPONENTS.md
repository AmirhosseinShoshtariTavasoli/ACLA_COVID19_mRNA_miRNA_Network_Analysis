## Drug–gene validation and VDGEI

The final drug–gene validation and study-specific VDGEI ranking were performed as an interactive AI-assisted evidence-synthesis process rather than by executing a local scoring program. The rubric is documented in `src/11_drug_prioritization/README.md`. No post-hoc executable has been invented for the repository.

## Figures

No dedicated manuscript figure-generation script was executed in the recovered project. The figures were assembled from frozen computational/reporting outputs. The repository therefore does not present reconstructed plotting code as original analysis code.
