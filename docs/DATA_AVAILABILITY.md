# Data availability

The study uses publicly available GEO data and does not redistribute the source expression files.

- SuperSeries: GSE243219
- mRNA: GSE243217
- miRNA: GSE243218

Users should retrieve the processed files and metadata directly from NCBI GEO. The included acquisition/integrity scripts document the expected project structure and validation logic.

External miRNA-target resources are also not redistributed. Obtain the corresponding versions from their original providers and follow their licenses/terms.
