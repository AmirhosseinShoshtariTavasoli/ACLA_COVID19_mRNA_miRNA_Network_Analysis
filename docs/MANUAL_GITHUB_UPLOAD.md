# Manual GitHub upload

1. Create a new GitHub repository named `ACLA_COVID19_mRNA_miRNA_Network_Analysis`.
2. Keep it empty when creating it (do not auto-create a README/license if you plan to upload this package as-is).
3. Extract the ZIP locally.
4. Open the extracted repository folder and upload its **contents** to the GitHub repository root, preserving directories.
5. Do not upload the outer ZIP file itself.
6. GitHub browser uploads should remain below the per-file size limit; this package intentionally excludes GEO expression matrices and large generated outputs.
7. Replace `REPLACE_WITH_USERNAME` in `CITATION.cff` after the repository URL is known.
8. Before tagging `v1.0.0`, complete `docs/LOCAL_FILES_TO_ADD.md` and rerun the repository validator.
