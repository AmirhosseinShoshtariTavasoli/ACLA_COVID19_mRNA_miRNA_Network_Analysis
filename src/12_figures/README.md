# Manuscript figures

No dedicated figure-generation script was executed for the manuscript figures in the recovered GSE243219 project. Figures were assembled from frozen analysis and reporting outputs.

Accordingly, this repository does not reconstruct plotting code after the fact or label newly written plotting code as part of the original executed analysis. Where figure source tables are available in the preserved reporting provenance (for example, D10V reporting tables/figure plans), they should be treated as the underlying data sources for presentation.
