# Data

No source expression matrices are included in GitHub.

Retrieve GSE243217 and GSE243218 from NCBI GEO under SuperSeries GSE243219. The executable acquisition/integrity scripts in `src/01_data_acquisition/` document the expected project layout and checks.

Do not commit:

- GEO raw/processed matrices that can be re-downloaded,
- large bootstrap checkpoint files,
- database redistribution files whose licenses do not permit redistribution,
- personal/local paths, credentials, or tokens.
