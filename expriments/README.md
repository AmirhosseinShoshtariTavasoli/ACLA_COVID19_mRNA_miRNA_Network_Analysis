# Experimental branches

A signed A-CLA extension was prospectively developed and benchmarked during method evaluation, but it was **not** used for the final GSE243219 biological partition because benchmarking did not demonstrate sufficient incremental value from signed-edge information.

The final manuscript analysis returned to the original published A-CLA applied to a topology-only all-association projection. Detailed rationale is preserved in `provenance/D10_AUTHORITATIVE_REPORT.md`.
